# Facility AI Twin design

The central object is a cutaway mechanical facility, a small working world that a visitor can inspect and disrupt. Surrounding controls are restrained, with one primary incident action. This is an operating demonstration for an ICTWAY discussion, not a marketing landing page.

Palette: ceramic #f3f6f8, ink #203244, engineering blue #315de0, sensor cyan #23a9bd, alert amber #e98a37, recovered green #218a69. Alert color follows actual incident state. No decorative gradient or dark command-center template.

Type: self-hosted Pretendard, Korean-first. Large readable mission statement, quiet supporting labels, tabular sensor values. Bold hierarchy is concentrated on the live twin.

Desktop: compact masthead; mission strip; large 3D facility with an open agent/robot narrative to its right; actual/counterfactual temperature trace and chronological evidence beneath. Mobile: live scene first, thumb-accessible incident action, a stacked explanation and evidence stream.

Signature: detailed metal equipment, pipes and a cutaway wall under soft architectural lighting. The visitor sees a fault glow, the route adapt to a physical obstruction, and the facility cool after a bounded intervention. Motion answers actions. Orbit, top, follow and thermal views make the same event readable from different perspectives.

Honesty: local agent is a rule-based decision engine. Lightweight robot uses kinematic autonomous navigation. Optional Go1 runs MuJoCo and an attributed public learned locomotion policy. The heat model is an illustrative simulation. No live ICTWAY integration, hardware validation, whole-brain learning, or real-world safety certification is implied.

Review: this avoids the generic dark neon dashboard and repeated stat cards. Facility geometry is the visual lead; the UI supports the incident story. Use icons only when useful, no emoji, retain visible keyboard focus, honor reduced motion, verify at 390 px and desktop.
